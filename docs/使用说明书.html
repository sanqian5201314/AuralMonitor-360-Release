AuralMonitor 360 — 用户使用说明书

版本 v2.0（Windows） · 多声道（7.1.4 / 9.1.6）BRIR 双耳空间音频监听软件（独立版 + VST3 插件）

说明：本安装包仅包含 AuralMonitor 360 本体（独立桌面版与 VST3 插件）及内置默认 BRIR 听音室脉冲，不捆绑任何第三方虚拟声卡或播放器安装程序。在 DAW 插件模式下开箱即用；若需在独立版中监听系统全局或播放器全景声，请按下方第 2 节指引自行前往官网安装虚拟声卡。

一、两种使用模式

使用模式 适用场景 是否需要虚拟声卡
推荐VST3 插件模式 Cubase / Nuendo / Reaper / Pro Tools / Studio One 等宿主内的 7.1.4 / 9.1.6 全景声混音与母带监听 不需要，直接插入多声道监听总线即可使用
独立版桌面独立模式 监听 Windows 系统声音、Apple Music、浏览器或本地全景声播放器输出 需要自行安装第三方虚拟声卡（如 VB-Cable 或 VB-Audio Matrix）

二、独立版虚拟声卡配置指南（自助下载安装）

独立版内置了 WASAPI Loopback 跨设备直通桥接引擎（支持无锁环形缓冲与自动重采样，免去采样率冲突），你只需先从官网装好虚拟声卡，剩下的连线由软件自动完成。

第 1 步：前往官网自行下载并安装虚拟声卡（二选一）

  • 日常推荐 · 免费VB-Cable Virtual Audio Device
    官网地址：https://vb-audio.com/Cable/
    下载解压后，右键以管理员身份运行 VBCABLE_Setup_x64.exe 安装，装完建议重启一次电脑。
  • 专业多声道 · 7.1.4 / 9.1.6VB-Audio Matrix
    官网地址：https://vb-audio.com/Matrix/
    适合需要 12 声道（7.1.4）或 16 声道（9.1.6）无损 ASIO / 多通道直通监听的专业用户。

第 2 步：启动 AuralMonitor 360 一键打通声音

  1. 双击打开 AuralMonitor 360 独立版。
  2. 在弹出的「音频输入与耳机直通设置」窗口中：
    • 播放器输入源：选择你刚装好的虚拟声卡（例如 CABLE Input 或 VBMatrix In 1）。
    • 物理输出设备：选择你的实体耳机或专业声卡（支持实体 ASIO 或 Windows Audio，并可选择耳机输出通道对如 Out 1+2）。
  3. 点击确认后，将 Windows 系统默认播放设备（或播放器的音频输出设备）设置为同一个虚拟声卡，即可直接从耳机听到空间音频监听效果。
避坑提示：请勿把「物理输出设备」也选成虚拟声卡，否则会形成声音回环或无声；输入选虚拟声卡、输出选你的实体耳机/声卡即可。

三、Apple Music 跑通杜比全景声教程（搭配 Final Spatial Audio / NSp）

Windows 版 Apple Music 默认只有在系统输出端点支持空间音频时，才会输出真正的杜比全景声（Dolby Atmos）。通过搭配第三方工具 Final Spatial Audio（简称 NSp / NativeSpatialPipe），即可在 Windows 上把 Apple Music 的全景声实时解码为 7.1.4（12 声道） 或 9.1.6（16 声道） 无损 PCM 音频流，再交由 AuralMonitor 360 进行 BRIR 双耳听音室渲染。

完整音频链路

Apple Music (Dolby Atmos) → Final Spatial Audio (NSp 实时解码 7.1.4 / 9.1.6) → 虚拟声卡 (VB-Audio Matrix) → AuralMonitor 360 (BRIR 空间渲染) → 实体耳机 / 专业声卡

详细配置步骤

  1. 开启 Apple Music 杜比全景声：在 Microsoft Store 安装 Windows 版 Apple Music，进入 设置 → 播放，将 杜比全景声（Dolby Atmos） 设为 始终打开（Always On）。
  2. 安装虚拟声卡：按上一节指引，自行前往官网安装 VB-Audio Matrix（推荐，原生支持 12 / 16 通道无损传输）。
  3. 安装并配置 Final Spatial Audio (NSp)：
    • 自行下载并安装 Final Spatial Audio (NSp / NativeSpatialPipe)；
    • 在 NSp 配置向导中选择输出声道布局为 7.1.4（12ch） 或 9.1.6（16ch）；
    • 将 NSp 的多声道输出目标指向 VB-Audio Matrix 的虚拟输入通道；
    • 在 Windows 系统声音设置中，将默认播放设备切换为 NSp 提供的空间音频输出端点，并确认系统「空间音效」处于开启状态。
  4. 在 AuralMonitor 360 中接入渲染：
    • 打开 AuralMonitor 360 独立版，在音频设置弹窗里将输入源设为 VBMatrix In 1（跨设备桥接模式）或 VB-Matrix VASIO-64A / VASIO-128（专业 ASIO 模式）；
    • 将物理输出设为你的实体耳机或专业声卡；
    • 在主界面确认声道格式与 NSp 保持一致（7.1.4 或 9.1.6）。
  5. 验证成功：在 Apple Music 播放任意带有「杜比全景声」标识的歌曲，观察 AuralMonitor 360 听音室视图——此时 12 个或 16 个扬声器电平表会同步独立跳动，代表已成功跑通真多声道全景声监听！

四、核心功能说明

功能模块 操作与用途说明
听音室视图（Room） 直观显示 5.1 / 7.1.4 / 9.1.6 各扬声器位置与实时声道电平；点击扬声器可单独控制 Mute（静音） / Solo（独奏），便于排查单声道细节。
BRIR 脉冲切换 软件已内置默认听音室 BRIR，打开即用；也支持直接把你自己的多声道 .wav BRIR 文件拖进软件窗口实时加载切换。
去混响（Dereverb） 可按起始时间（ms）、窗长与衰减量（dB）平滑削减房间后期混响尾音，在保留声像定位的同时让声音更干脆。
监听 EQ 与实时频谱 内置多段监听均衡器与实时频谱曲线显示，支持鼠标拖拽微调频点增益与 Q 值。
耳机频响补偿 内置多款常见监听耳机的目标曲线校准预设，一键修正耳机自身频响染色，还原更平直的监听参考。
Bypass / Dim / A-B Bypass 采用 ITU-R BS.775 声压补偿下混，对比时不炸耳；Dim 一键衰减监听音量；A / B 槽 支持两套参数快速切换与复制对比。
粉噪校准（Pink Noise） 内置音频线程安全的粉红噪声发生器，配合单路 Solo 可用于校验通道顺序与各扬声器响度一致性。
迷你视图（Mini） 一键折叠为紧凑控制条，方便在混音界面角落常驻不遮挡工程窗口。

五、常见问题排查（FAQ）

1. 独立版打开后听不到声音？

  • 检查 Windows 右下角小喇叭的播放设备是否已切换到虚拟声卡（如 CABLE Input）。
  • 检查软件内的「物理输出设备」是否指向你当前戴着的实体耳机或声卡，且顶部未处于 Mute 状态。

2. 专业声卡 ASIO 模式下想用耳机 3/4 通道听怎么办？

  • 在音频设置弹窗里，选择你的实体 ASIO 声卡后，将「耳机输出通道对」切换为 Out 3+4 即可，无需改动宿主或其他路由。

3. 如何更换自己的听音室 BRIR？

  • 准备多声道双耳 .wav 格式的 BRIR 文件（例如 24 声道对应 7.1.4 的 12 路左右耳脉冲，或 32 声道对应 9.1.6），直接用鼠标拖进 AuralMonitor 360 主界面松开即可生效。
